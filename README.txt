# A Little Love Invitation ❤️

## Run it
1. Extract the ZIP folder.
2. Open `index.html` in a modern browser.
3. Click the envelope to reveal the letter.

## Personalize it
Open `script.js` and edit the `CONFIG` values near the top:
- `sender`: your name
- `recipient`: their name
- `message`: your own message

## Share it
For a shareable link, upload the folder to a static website host such as GitHub Pages, Netlify, or Vercel, then open the hosted page and use **Share this invitation**. The link includes the sender, recipient, and message from `CONFIG`, so the recipient sees your personalized invitation. Opening `index.html` locally cannot create a public link; the share button will remind you to publish the page first.

## Included
- `index.html` — website structure
- `style.css` — responsive design and animations
- `script.js` — interactions, typing effect, hearts, sound toggle and share button

Fonts load from Google Fonts when internet access is available; system fallbacks are included.
